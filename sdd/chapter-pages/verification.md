- 原有來源 ID、時間精度、回覆限制、計數差額與中英文對應。

- 子路徑部署下的 metadata、跨語言與資源連結。
- 舊首頁的錨點對照、靜態入口與紀錄頁返回同語言搜尋頁的路徑。

## 瀏覽器流程

使用獨立 Headless Chrome 工作階段，在桌面寬度 1440 與手機寬度 390 驗證兩種語言：

- 九頁皆回傳 HTTP 200，各頁各一個 H1，沒有水平溢出或 JavaScript 例外；檢視首頁、搜尋頁及紀錄頁畫面。
- 爭點引用能到達指定紀錄，紀錄仍有原始來源連結；紀錄頁搜尋入口返回同語言的全站搜尋。
- 搜尋可匹配僅存在於查核註記的文字；討論串篩選、作者控制項、清除及無結果提示可操作。
- 舊首頁的 Facebook 與 GitHub 紀錄錨點能到達新位置；返回鍵不回到轉址迴圈。
- 複製連結使用新頁面路徑；切換語言保留來源頁與紀錄 ID。
- 未移動的 `#brief`、未知錨點及 `#__proto__` 留在首頁，無錯誤導向。
- 停用 JavaScript 並使用減少動態效果設定時，舊錨點的靜態連結可前往新紀錄；四個紀錄頁合計 144 筆，索引保留 144 個可用連結。
- 模擬搜尋索引網路失敗時，有明確替代提示，全部 144 筆靜態紀錄連結仍可使用。
